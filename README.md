# Healthcare Appointment Intelligence

## Project Overview
This project analyzes healthcare appointment data to identify factors contributing to patient no-shows and predicts whether a patient will miss an appointment using Machine Learning. An interactive Power BI dashboard is also developed to visualize insights and support decision-making.

## Objectives
- Analyze healthcare appointment data.
- Identify factors influencing patient no-shows.
- Build predictive machine learning models.
- Classify patients based on no-show risk.
- Develop an interactive Power BI dashboard.

## Key Insights
- Waiting time is the strongest predictor of patient no-shows.
- Teenagers and young adults have higher no-show rates.
- SMS reminders improve attendance for longer waiting periods.
- Some neighborhoods consistently have higher no-show rates.
- Machine learning effectively predicts patient no-show risk.
